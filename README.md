# Sanctuary Living — Campus Housing Transformation Platform

A full-stack product and operations platform reimagining student campus accommodation around four enforceable contractual SLA pillars, rent transparency, and interactive 3D WebGL space previews.

**Live Deployment:** https://sanctuary-campus-living.vercel.app

## Highlights
- **Interactive 3D Campus & Room Configurator (`Three.js / WebGL`)**: Real-time 3D exploration of campus blocks (`js/three-campus.js`), Single/Double/Triple room layouts (`js/three-room.js`), and security infrastructure (`js/three-security.js`).
- **4 Contractual SLA Pillars**:
  1. **48-Hour Hygiene & Maintenance SLA** with digital QR station logs and financial vendor accountability.
  2. **<10-Minute Emergency Safety** with biometric entry and SOS beacon dispatch architecture.
  3. **Radical Rent Transparency** with zero hidden fees and a dedicated 15% student subsidy reserve.
  4. **Student-Governed Mess & Nutrition** backed by FSSAI audits and meal rebate tracking.
- **12-Month Phased Implementation Roadmap** & Project Management Charter.

## Tech Stack
- HTML5, Tailwind CSS
- Vanilla ES6+ JavaScript (`js/app.js`)
- Three.js / WebGL (`js/three-*.js`)
- Deployed on Vercel
